# Release checklist

## Commercial

- [ ] Product names, variants, pricing, discounts, guarantees, and shipping approved.
- [ ] Claims and specifications validated against the real product/manual.
- [ ] Reviews are authentic and provider-approved.
- [ ] Add-ons and bundles are physically and financially valid.

## Functional

- [ ] Variant changes synchronize price, media, SKU, availability, form, add-ons, and sticky ATC.
- [ ] Add to Cart, quantity, remove, discounts, cart upsells, and checkout work.
- [ ] Empty, loading, unavailable, sold-out, error, and recovery states work.
- [ ] Theme Editor can add, remove, hide, and reorder intended blocks.

## Experience

- [ ] Home and PDP match the approved hierarchy and brand system.
- [ ] Mobile, tablet, and desktop have intentional composition.
- [ ] Sticky elements do not overlap content, chat, cookies, or safe areas.
- [ ] Keyboard, focus, screen-reader names, live updates, and reduced motion verified.

## Technical

- [ ] Theme Check has no new errors.
- [ ] JSON and schemas validate.
- [ ] No unapproved apps, dependencies, trackers, or copied PETLIBRO content.
- [ ] LCP, CLS, INP, media, and custom-JS budgets evaluated.
- [ ] Product, Offer, FAQ, and rating structured data are consistent.
- [ ] Analytics events do not double fire.

## Release

- [ ] Zero P0/P1 defects.
- [ ] Final result report approved by Work.
- [ ] Git state clean and release commit/tag recorded.
- [ ] Backup/theme duplicate exists.
- [ ] Production publish explicitly authorized.
