# RELIVANOW Theme

Shopify Online Store 2.0 theme for RELIVANOW Smart Pet Care, built on Horizon 4.1.1.

## Start here

1. Read `AGENTS.md`.
2. Review `PROJECT_STATUS.md` and `TASKS.md`.
3. Open the active file under `tasks/`.
4. Follow `docs/CODEX_WORKFLOW.md`.

The PETLIBRO material in `docs/PETLIBRO_AUDIT.md` is a benchmark audit, not a source of code or protected content.

## Current stage

Project control pack installed. `TASK-001-BASELINE-AUDIT.md` is the only task ready for execution.

## Theme directories

- `assets/`: CSS, JavaScript, SVG, and theme assets.
- `blocks/`: Horizon theme blocks.
- `config/`: Theme settings schema and saved settings.
- `layout/`: Shopify layouts.
- `locales/`: Theme translations.
- `sections/`: Shopify sections.
- `snippets/`: Reusable Liquid fragments.
- `templates/`: JSON/Liquid templates.

## Project control

- `docs/`: approved product, design, architecture, and QA context.
- `tasks/`: bounded execution prompts.
- `reports/`: evidence and handoff from Codex to ChatGPT Work.
